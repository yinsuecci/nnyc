中继节点

过载、离线或维护节点不再接收新会话。已有会话不强制迁移。

接入一台服务器

登记节点后，在对应服务器部署中继进程。这里不保存 SSH 密码，也不会自动安装软件。

默认达到 90% 停接，低于 90% 即恢复。所有节点满载时明确拒绝新中继，不挤占已有会话。
